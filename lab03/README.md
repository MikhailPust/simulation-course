### Клеточные автоматы. Лесные пожары (GUI)

**Задание:**  
Реализовать моделирование возникновения и распространения лесных пожаров с использованием двумерного клеточного автомата.

**Требования:**
- реализовать **не менее трёх дополнительных правил** поведения системы.

## Описание модели

Поле моделирования представляет собой двумерную сетку клеток размером 80×60
(640×480 пикселей, размер одной клетки — 8×8 пикселей).
Каждая клетка в каждый момент времени находится в одном из пяти состояний:

| Состояние | Значение | Цвет        | Описание              |
|-----------|----------|-------------|-----------------------|
| EMPTY     | 0        | Коричневый  | Пустая земля          |
| TREE      | 1        | Зелёный     | Живое дерево          |
| BURNING   | 2        | Оранжево-красный | Горит            |
| BURNED    | 3        | Серый       | Сгорело (угли)        |
| WATER     | 4        | Синий       | Вода (река или озеро) |


## Основные правила

1. Горящая клетка → Сгоревшая
2. Сгоревшая клетка → Пустая земля
3. Дерево загорается если рядом есть горящий сосед (окрестность фон Неймана)
4. На пустой клетке с вероятностью  вырастает новое дерево

## Дополнительные правила

1. **Молния** — дерево загорается случайно с вероятностью 
2. **Водоёмы** — реки и озёра блокируют распространение огня
3. **Ветер** — огонь от левого соседа распространяется всегда,
от остальных направлений — с вероятностью 


## Генерация карты

Поле заполняется деревьями с заданной плотностью, затем поверх генерируются
водоёмы — случайно либо река (извилистая полоса через всё поле),
либо озеро (округлое пятно). В центр помещается начальный очаг пожара.
