### Метод конечных разностей для уравнения теплопроводности

**Задание:**  
Реализовать моделирование изменения температуры в пластине на основе одномерного уравнения теплопроводности с использованием метода конечных разностей.

Выполнить моделирование с различными шагами по времени и по пространству.  
Заполнить таблицу значений температуры в центральной точке пластины после 2 секунд модельного времени.

| Шаг по времени, с \ Шаг по пространству, м | 0.1 | 0.01 | 0.001 | 0.0001 |
|-------------------------------------------|-----|------|-------|--------|
| 0.1 | | | | |
| 0.01 | | | | |
| 0.001 | | | | |
| 0.0001 | | | | |

**Сделать вывод.**

**Материал:** алюминий.
**плотность:** 2700.

### Вывод
**1. ** На основе проведенных опытов видно , что при большем шаге по пространству (0,1) результат получается крайне не точным. Это происходит потому , что при шаге 0,1 сетка получается слишком грубой , компьютер просто проскакиевает важные изменения внтури пластины и в итоге мы видим лишь общее направление графика.

**2. ** При постепенном уменьшении шага видно, что значение температуры в центре практически перестает меняться (стабилизируется). Дальнейшее дробление сетки (например, до 0.0001) уже не дает видимого прироста точности, так как значения $T$ меняются лишь в далеких знаках после запятой.

**3. ** В ходе тестов стало видно, что начиная с определенных значений (например, при переходе от шага 0.01 к 0.001), итоговая температура в центре перестает сильно «прыгать» и начинает различаться только в глубоких знаках после запятой.

**4. ** С шагом по времени ситуация аналогична: чем меньше значение, тем точнее и стабильнее результат.

**5. ** На основе проведенных тестов можно сделать однозначный вывод: самый точный результат достигается при сочетании минимальных значений шагов как по пространству ($h$), так и по времени ($\tau$).
